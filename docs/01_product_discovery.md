# Phase 1: Product Discovery

## 1. Define the Vision
**What problem does ProdOS solve?**
Modern professionals and creators suffer from "app fatigue." They use one app for tasks (Todoist), another for habits (Habitica), another for finance (Mint/Excel), and another for health (Apple Health). ProdOS solves this by providing a unified, context-switching personal operating system.

**Who is it for?**
High-performing individuals who treat their personal and professional lives with equal rigor. It is designed for people who execute, not just plan.

**Why is it better than Notion/Todoist?**
- Notion is too flexible, requiring constant maintenance and leading to cluttered wikis.
- Todoist is too rigid and only handles tasks. 
- ProdOS uses a rigid, optimized "shell" that changes context (Personal, Finance, Work) instead of changing features, providing focus without the friction of context switching between different apps.

## 4. Prioritization (MoSCoW Method)

### MUST HAVE (The MVP Foundation)
- User Authentication (Login)
- Global Dashboard Shell (Workspace Selector)
- Contextual Workspaces (Personal Life, Financial Dashboard)
- Task Management (Add, Complete, View in Drawer)
- Goals Rail (Static filtering)

### SHOULD HAVE (Fast Follows)
- Habit Tracking integrated into Personal Life
- Calendar Side Panel (Local first)
- Basic Finance Analytics (Net Worth, Distribution)

### COULD HAVE (Future Polish)
- AI-Assisted Finance Logging (Natural Language Parsing via OpenAI)
- Real Health Data Sync (Apple Health/Google Fit APIs)
- GitHub Activity Monitor (Skill Check workspace)
- Google Calendar API Integration

### WON'T HAVE (Out of Scope for MVP)
- Team Collaboration / Multiplayer mode
- Native Mobile App (iOS/Android)
- Complex Project Management (Gantt charts, Kanban boards)
